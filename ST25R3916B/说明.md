# 天线说明：

我已经设计好了天线了，根据测量的值输入的下面：

| 参数                        | 数值  | 单位 |
| --------------------------- | ----- | ---- |
| Length (amax)               | 40.64 | mm   |
| Width (bmax)                | 50.8  | mm   |
| Track width (w)             | 508   | µm   |
| Gap between tracks (g)      | 381   | µm   |
| Additional Overlap Area (A) | 0     | mm2  |
| Track Thickness             | 35    | µm   |
| Number of Turns (N)         | 4     |      |
| Turn exponent (E)           | 1.66  |      |
| PCB Thickness               | 1.59  | mm   |
| Er                          | 4.3   |      |

得到天线参数：

| Inductance (Lant)     | 1683 | nH   |
| --------------------- | ---- | ---- |
| Lant min              | 1548 | nH   |
| Lant max              | 2190 | nH   |
| Capacitance (Cant)    | 2.0  | pF   |
| Resistance (Rant)     | 1.47 | Ω    |
| Self resonance (Fres) | 86   | MHz  |

天线特性默认值如下

| Q                | 20   |      |
| ---------------- | ---- | ---- |
| Target impedance | 20   | Ω    |
| fEMC cut off     | 22   | MHz  |
| L0               | 160  | nH   |

## 一、目录结构总览
1. datasheet：硬件/射频/软件参考PDF手册
2. software：STM32嵌入式NFC固件源码包
3. tool：Windows电脑端调试工具

## 二、datasheet 文件夹内各PDF文件说明
1. an5240-layout-recommendations-xxx.pdf
    作用：ST25R3916B系列PCB射频布局规范，画板必看，包含射频走线、地层分割、数模隔离、接地规则，解决EMI超标、读卡距离衰减问题。
2. an5276-antenna-design-xxx.pdf
    作用：NFC天线全套设计指南，适配你两款13.56MHz IPEX天线，讲解线圈电感计算、π型匹配网络、吸波材料补偿、阻抗调试方法，调天线核心文档。
3. an6313-migrating-from-st25r39xx-xxx.pdf
    作用：芯片迁移手册，用于ST25R3916B切换至ST25R300/210/500系列时查阅；仅做3916B读卡器可暂时不看。
4. es0649-st25r3916b-device-limitations.pdf
    作用：芯片勘误表，记录ST25R3916B硬件BUG、功能限制、使用禁忌，PCB和软件设计前必须通读，规避量产故障。
5. st25r3916b.pdf
    作用：芯片原厂主规格书（DS），包含引脚定义、电气参数、射频功率、时序、工作模式，硬件设计基础文档。
6. stsw-st25r004.pdf
    作用：天线匹配计算工具配套说明书，使用STSW-ST25R004软件遇到参数疑问时查阅，无需提前精读。
7. um2890-rfnfc-abstraction-layer-rfal.pdf
    作用：RFAL射频抽象层软件手册，写单片机NFC固件必看，提供全套读卡、标签读写、P2P交互标准API说明。

## 三、software 文件夹固件包说明
1. x-cube-nfc6.zip
    作用：STM32Cube官方NFC开发扩展包，内置完整工程例程，包含ISO14443A/B、15693标签读写、卡模拟、点对点功能，STM32开发读卡器首选底层工程。
2. STSW-ST25RFAL002.zip
    作用：RFAL射频抽象层核心协议库，统一API兼容ST25R全系列芯片，一套代码可适配3916B/300等芯片，降低后续换芯片改造成本。
3. stsw-st25rlib002.zip
    作用：轻量化ST25通用NFC底层库，无STM32Cube依赖，适配裸机MCU、其他品牌单片机平台。

## 四、tool 文件夹PC调试工具说明
1. en.STSW-ST25R010_ST25R3916_Discovery_GUI.zip
    作用：STEVAL-25R3916B官方评估板配套Windows上位机GUI+驱动，用于评估板快速验证读卡功能。
2. STSW-ST25PC001.zip
    作用：ST25PC-NFC可视化调试上位机，电脑连接开发板后，可图形化读卡、读写标签、查看射频交互日志、实测读卡距离，硬件调试必备。
3. STSW-ST25R004.zip
    作用：天线匹配参数计算工具，输入天线实测电感、电阻，自动输出匹配电容数值，快速完成射频匹配网络设计。
